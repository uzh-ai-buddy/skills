# Teaching Planner Artifacts

## Purpose
- Deliver lesson plans and semester plans in structured markdown formats for educational planning.
- Facilitate clear tracking of learning objectives, delivery formats, and didactic methods for courses or programs.

## When to use
- The user requests a lesson plan or semester plan for a course or program.
- The user wants to organize or track teaching content, objectives, session formats, or didactic approaches.
- The user needs markdown templates with placeholders to easily fill in or adapt for specific teaching scenarios.

## Examples
- "Create a semester plan for my neuroscience course."
- "Generate a lesson plan template with learning objectives and activities."

## Output requirements
- Follow `librechat-artifacts-core` wrapper rules.
- Provide 2–5 line summary in chat and exactly one artifact.
- Include a markdown table with placeholders for user input, following the provided templates.

- Lesson plan template:
  `references/01-lesson-plan-template.md`
- Semester plan template:
