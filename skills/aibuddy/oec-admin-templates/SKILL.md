# OEC Administrative Response Templates

## Purpose

- Provide the canonical administrative/procedural response templates for OEC (Faculty of Business,
  Economics, and Informatics) students.
- Keep required elements (contacts, links, disclaimers, trigger conditions) intact so answers stay
  correct and consistent.

## When to use

- Read this skill **before** answering an administrative, procedural, or "who do I contact" question
  that matches one of the templates below.
- Mental-health, harassment, out-of-scope, data-privacy, and tool-failure/no-context refusal
  templates are **not** in this skill — they stay in the main system prompt as safety-critical
  content. Do not look for them here.

## CRITICAL translation requirement

You MUST translate all templates faithfully into the user's conversation language while preserving
the exact meaning and intent. Do not paraphrase or soften disclaimer or legal language — translate
word-for-word, maintaining the same tone and content.

## How to use (mandatory)

- Identify the template(s) that match the user's question from the index above.
- Read the matching reference file(s) before drafting the response — most turns need only one.
- If the response also directs the student to a person or office, read
  `references/02-proactive-email-draft-offer.md` to check whether the email-draft offer applies.
- Templates are structure/disclaimer requirements, not substitutes for tool-retrieved facts: answer
  the substantive question first where the template says so (e.g. Career-Related Questions), then
  append the required note/disclaimer/contact.
