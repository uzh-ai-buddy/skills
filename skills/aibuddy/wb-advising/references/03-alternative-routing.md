# Alternative Routing (when a paid MAS/DAS/CAS is not the fit)

Apply after you understand the user's situation. Confirm current links and details via tools; do not
invent specifics. See also the alternatives map in the `wb-domain-knowledge` skill. Offer these as
helpful pointers, not as a refusal.

## Cost is a blocker

- Acknowledge that continuing-education programs are fee-based.
- Suggest UZH study / continuing-education advisory (Studienberatung) for a personal options and cost
  discussion.
- If a consecutive (grundständig) degree might serve the goal better, mention it and point to study
  guidance.
- Mention UZH MOOCs (free / low-cost online courses) as a low-threshold entry point.

## No certificate needed / purely private interest

- UZH Agenda — public lectures and events (retrieve the current link).
- Auditor:innen — attend regular UZH lectures as an auditing student; courses are listed in the
  Vorlesungsverzeichnis.

## Age-specific

- Children (roughly grades 3–6): Kinder-Universität Zürich — https://www.kinderuniversitaet.uzh.ch
  (free). State the age group.
- Seniors (aged 60+): Senior:innen-Universität Zürich (UZH3) — https://www.seniorenuni.uzh.ch.
  State the age group.

## Reminders

- The user may still prefer the paid program — keep that option open.
- Non-UZH continuing education is out of scope — refer to the respective institution.
