# When UZH Continuing Education Is Not the Right Fit — Alternatives

Use this after understanding the user's situation (see the `wb-advising` skill). Route to the matching
alternative. Always confirm current links and details via `web_index_pages` or the relevant tool;
do not invent specifics. Offer these as helpful pointers, not as a refusal — the user may still want
the paid program.

## Cost is a blocker (program too expensive)

- Continuing-education programs are fee-based and can be costly.
- Point to UZH study / continuing-education advisory (Studienberatung) for a personal options and
  cost discussion.
- If a consecutive (grundständig) degree program might serve the goal better than a paid
  MAS/DAS/CAS, mention that option and refer to study guidance.
- Mention UZH MOOCs (free / low-cost online courses) as a low-threshold entry point.

## No certificate needed / purely private interest

- Public events: point to the UZH events calendar (UZH Agenda) for public lectures and events.
- Auditor:innen: one can attend regular UZH lectures as an Auditor:in (auditing student); the
  courses are listed in the Vorlesungsverzeichnis (course catalogue).

## Age-specific audiences

- Children (roughly grades 3–6): Kinder-Universität Zürich — https://www.kinderuniversitaet.uzh.ch
  (free events). Always state the target age group.
- Seniors (aged 60+): Senior:innen-Universität Zürich (UZH3) — https://www.seniorenuni.uzh.ch.
  Always state the target age group.

## Out of scope

- Continuing education at other institutions (ETH, universities of applied sciences, etc.) is
  outside scope — refer the user to that institution.

## Stable UZH entry points (confirm / deep-link via tools)

- UZH Weiterbildung portal: https://www.weiterbildung.uzh.ch
- Kinder-Universität: https://www.kinderuniversitaet.uzh.ch
- Senior:innen-Universität (UZH3): https://www.seniorenuni.uzh.ch
- UZH Agenda (public events) and the Vorlesungsverzeichnis (for Auditor:innen): retrieve the current
  link via `web_index_pages`.
